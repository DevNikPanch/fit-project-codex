Настольное приложение для автоматического анализа техники отжиманий по короткому видео. Пользователь выбирает файл, а программа с помощью нейросетевых алгоритмов определяет ключевые точки тела, рассчитывает углы и выдает персональные текстовые рекомендации по улучшению техники выполнения упражнения.

Проект создан в рамках учебного прототипа с применением генеративного ИИ (OpenAI Codex) и демонстрирует навыки работы с компьютерным зрением, библиотекой MediaPipe, обработкой видео и построением GUI на Tkinter.

---

## 🎯 Возможности

- 🎥 **Загрузка видео** в форматах `.mp4`, `.mov`, `.avi`, `.mkv`
- 🧠 **Обнаружение позы** с помощью MediaPipe Pose Landmarker (33 ключевые точки тела)
- 📊 **Расчёт метрик:** угол в локтях, ширина постановки рук, прямая линия корпуса, асимметрия рук
- 🔢 **Подсчёт примерного числа повторений** по смене положения локтей (верх–низ–верх)
- 💬 **Выдача текстовых советов** на русском языке:
  - «Локти слишком широко»
  - «Неполная нижняя фаза»
  - «Потеря прямой линии корпуса»
  - «Асимметрия рук»
- 🪟 **Простой графический интерфейс** на Tkinter: выбор файла, кнопка «Анализировать», поле с результатом

> ⚠️ Приложение не является медицинским инструментом и не заменяет профессионального тренера. Это первая версия, работающая по правилам, заданным поверх ключевых точек тела.

---

## 🎬 Требования к видео

Для корректного анализа рекомендуется следующий ракурс: **сбоку под углом 30–45°**.

- Камера на уровне груди
- Всё тело видно полностью (голова, руки, корпус, ноги)
- Плечи, локти, таз и стопы не перекрыты
- Хорошее равномерное освещение
- Длительность до 30 секунд; короткие видео (2–5 повторений) также поддерживаются
- В кадре только один человек

## 🧠 Особенности реализации

- **Анализ позы в реальном времени** — обработка видео происходит кадр за кадром (~10 кадров/сек) без загрузки всего файла в память
- **Автоматическая загрузка модели** — при первом запуске MediaPipe скачивает файл модели в локальную папку `models`
- **Геометрический подход к расчёту метрик** — углы и расстояния вычисляются на основе координат ключевых точек, без использования дополнительных ML-моделей
- **Понятные текстовые рекомендации** — сложные метрики преобразуются в короткие и ясные советы на русском языке
- **Модульная архитектура** — логика анализа отделена от GUI, что упрощает добавление новых упражнений
- **Использование OpenAI Codex** — часть кода была сгенерирована с помощью генеративного ИИ, что позволило ускорить разработку и изучить применение AI-ассистентов в реальных задачах
