# Анализ техники отжиманий по видео

Учебный прототип desktop-приложения на Python для Windows. Пользователь выбирает видео длительностью до 30 секунд, приложение находит ключевые точки тела через MediaPipe Pose Landmarker и выдает текстовые советы по технике отжиманий.

## 1. Что получится

В первой версии реализовано одно упражнение: отжимание. Приложение:

- открывает окно Tkinter;
- позволяет выбрать видеофайл `.mp4`, `.mov`, `.avi` или `.mkv`;
- скачивает модель MediaPipe при первом запуске;
- анализирует примерно 10 кадров в секунду;
- считает примерное число повторений;
- выводит советы: локти слишком широко, неполная верхняя/нижняя фаза, потеря прямой линии корпуса, асимметрия рук.

Это не медицинский инструмент и не замена тренера. Это стартовая версия с правилами поверх ключевых точек тела.

## 2. Как снимать видео

Для этой версии приложение выбирает такой ракурс: сбоку под 30-45 градусов.

Правила съемки:

- камера на уровне груди;
- все тело видно полностью;
- обе руки, плечи, таз и стопы не закрыты;
- хорошее освещение;
- длительность до 30 секунд; короткие видео тоже поддерживаются;
- в кадре один человек;
- лучше снять 2-5 повторений без лишних пауз.

## 3. Какие библиотеки используются

- `mediapipe` - нейросетевой анализ позы и 33 ключевые точки тела.
- `opencv-python` - чтение видео по кадрам.
- `numpy` - расчеты углов и расстояний.
- `tkinter` - графический интерфейс. Он обычно идет вместе с Python, отдельно устанавливать не нужно.

## 4. Как устроен код

Главный файл: `app.py`.

Основные части:

- `PushupAnalyzerApp` создает окно, кнопку выбора видео и поле результата.
- `analyze_pushup_video()` открывает видео, отправляет кадры в MediaPipe и собирает метрики.
- `metrics_from_landmarks()` достает из ключевых точек углы локтей, линию корпуса, ширину локтей.
- `build_pushup_advice()` превращает числа в понятные советы.
- `count_repetitions()` грубо считает повторения по смене положения локтей: верх - низ - верх.

## 5. Запуск приложения

Каждый раз перед запуском активируйте окружение:

```powershell
cd D:\Programming\fit-project-codex
.\.venv\Scripts\Activate.ps1
```

Запустите приложение:

```powershell
python app.py
```

При первом запуске приложение скачает файл модели в папку `models`. Нужен интернет.

## 6. Проверка работы

1. Снимите видео отжиманий длительностью до 30 секунд.
2. Запустите `python app.py`.
3. Нажмите `Выбрать видео`.
4. Выберите файл.
5. Нажмите `Анализировать`.
6. Дождитесь текста результата.

Если приложение пишет, что позу видно нестабильно, переснимите видео: отойдите дальше, включите больше света, убедитесь, что руки, корпус и стопы не выходят из кадра.

## 7. Как развивать проект дальше

Следующий нормальный шаг - разделить код на модули:

```text
fit-project-codex/
  app.py
  requirements.txt
  models/
  analyzers/
    pushup.py
    squat.py
    plank.py
```

Для каждого упражнения можно сделать отдельную функцию анализа. Общая часть с MediaPipe останется одна, а правила для отжиманий, приседаний и планки будут разными.
